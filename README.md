# Python Operators – Homework

This repository contains my Python homework on **Arithmetic Operators** and **Comparison Operators** using different fundamental data types.

## 📚 Topics Covered

### 1. Arithmetic Operators

The following arithmetic operators are demonstrated:

* `+` Addition
* `-` Subtraction
* `*` Multiplication
* `/` Division
* `//` Floor Division
* `%` Modulus

### 2. Comparison Operators

The following comparison operators are demonstrated:

* `>` Greater than
* `<` Less than
* `>=` Greater than or equal to
* `<=` Less than or equal to
* `==` Equal to
* `!=` Not equal to

## 🔢 Fundamental Data Types Used

The homework demonstrates operations using:

* `int`
* `float`
* `str`
* `complex`
* `bool`

Different combinations of these data types are used to understand which operations are supported and how Python handles different data types.

## 📂 Files

| File                             | Description                                    |

| `28HW_Arithmetic_operator.ipynb` | Arithmetic operators with different data types |

## 🎯 Objective

The objective of this homework is to understand how Arithmetic and Comparison Operators work with different fundamental data types in Python and to identify valid and invalid operations between different data types.
